Role vocabulary v1

Terms of the RoleCredential v1 context. Credentials are checked with the RoleCredential v1 JSON Schema.

RoleCredential

Class. A verifiable credential issued by the organization that grants its subject one role in the pipeline of one repository. The holder is credentialSubject.id, the kind of actor it is credentialSubject.type, and the issue time issuanceDate.

Actor types

The value of credentialSubject.type. Each role belongs to one type.

Person
A human actor who acts through their own agent. Roles: Authorized Maintainer, Release Approver.
Stage
An automated pipeline stage with its own agent and runner. Roles: Builder, Tester, Publisher.
Service
A long-running service outside the pipeline steps. Roles: Release Custodian, Deploy Gate.

Role

Class. A pipeline role. Its values are listed below.

role

Property. The pipeline role granted to the credential subject. Its value is one of the roles below.

scope

Property. The repository the role applies to, as its GitHub URL, for example https://github.com/chain-of-trust-lab/rest-api.

Roles

AuthorizedMaintainer: Authorized Maintainer
A person allowed to commit to the repository. Issues Source committed credentials.
ReleaseApprover: Release Approver
A person who approves a built image for release. Issues Image approved credentials.
Builder: Builder
The build stage. Issues Package built and Image built credentials.
Tester: Tester
The test stage. Issues the tested credentials.
Publisher: Publisher
The deliver stage. Publishes the package and the image, and issues the published credentials.
DeployGate: Deploy Gate
Verifies the chain of step credentials before deployment. Issues Image deployed credentials.
ReleaseCustodian: Release Custodian
The project's release holder. Collects the step credentials and presents the chain to the deploy gate.
